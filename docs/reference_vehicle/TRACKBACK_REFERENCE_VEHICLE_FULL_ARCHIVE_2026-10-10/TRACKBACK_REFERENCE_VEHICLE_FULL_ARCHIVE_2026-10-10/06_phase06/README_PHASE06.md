# Phase 06 패키지

이 폴더는 Phase 05 Requirements Engineering 이후의 **Test Case & Verification Engineering** 초안이다.

## 파일

- `06_TEST_VERIFICATION_ENGINEERING_KO.md` — 전체 설계 본문
- `06_LF_TEST_CASE_CANDIDATES.csv` — 74 LF별 기본 TC 후보
- `06_REQUIREMENT_VERIFICATION_MATRIX.csv` — 180 요구사항 후보별 검증 전략
- `06_REQUIREMENT_TC_TRACEABILITY.csv` — Requirement→TC draft trace
- `06_CURRENT_RUNTIME_REGRESSION_CANDIDATES.csv` — 현재 구현 회귀/특성화 후보 23개
- `06_PROPULSION_TC_CROSSWALK.csv` — 기존 Propulsion reference TC와 감사상 current TC ID 구분
- `06_VERIFICATION_TECHNIQUE_CAPABILITY.csv` — 검증 기법별 현재 capability
- `06_ORACLE_VERDICT_POLICY_KO.md` — Expected/Oracle/PASS/FAIL 규칙
- `06_TEST_TECHNIQUES_COVERAGE_KO.md` — Pairwise, B2B, interface, coverage 등 가이드
