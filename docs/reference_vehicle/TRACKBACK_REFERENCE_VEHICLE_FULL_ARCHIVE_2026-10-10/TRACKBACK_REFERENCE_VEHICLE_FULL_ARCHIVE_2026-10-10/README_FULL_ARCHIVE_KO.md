# TRACKBACK Reference Vehicle 전체 아카이브

생성일: 2026-10-10

이 아카이브는 현재 대화에서 생성·검토한 TRACKBACK 차량 참조 아키텍처 관련 파일을 한 번에 보관/이동하기 위한 전체 묶음이다.

## 포함 범위
- 원본 참고문서 및 제품/검증 reconciliation 자료
- Phase 01~07 설계 산출물
- Phase 03/04 설계 감사 자료
- 2026-10-07 코드 대조 감사 보고서 5종
- 감사 반영 v0.2 검토본
- 개발/감사용 Codex 프롬프트

## 제외 범위
- 과거 전달용 ZIP 파일 자체(중복 방지)
- TRACKBACK와 무관한 취업 문서, 이미지, 일반 업로드 파일
- 실제 TraceBack 소스 저장소 전체

## 주의
이 아카이브는 '전체 보존용'이며, 모든 파일이 canonical source of truth라는 뜻은 아니다.
현재 canonicalization 전 단계이므로 review_v0.2, phase별 초안, 감사 산출물이 함께 포함되어 있다.
향후 Phase 07.5에서 docs/reference_vehicle의 canonical 구조를 별도로 정리해야 한다.
