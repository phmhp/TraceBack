# 플레이 UX·아키텍처 표현 검토 — 2026-10-30

## 같은 날 추가 화면 점검

- 1063×704 화면에서 기술 선택지는 분야별 탭, 선택지 카드, 동작 그림을 한 화면에 배치했다. `기능 트리 · E/E 연결`의 System·Domain·Function도 화면마다 한 핵심 그림과 짧은 조작 경로만 보이게 정리했다. 마지막 설계 지도는 왼쪽 3D, 오른쪽 선택 관점과 저장된 기능 그래프로 나눈다. 이 크기에서 각 구조 화면의 페이지 스크롤과 Domain 카드의 텍스트 겹침을 확인해 고쳤다.
- 조립대의 임시 좌석 형상을 삭제하고, 이미 장착한 부품의 색을 유지했다. 내연기관차와 EV의 부품 변화를 부품별 이전/이후와 이유로 보이고, 긴 내용은 도움말로 접었다. 우측 조작·조건·성패를 우선 표시한다.
- SW 실행에서 현재 블록으로 자동 이동하고 독립 계산 묶음을 나란히 보여준다. 같은 의존 단계는 실제 ECU에서 동시에 실행됐다는 뜻이 아니다. 마지막 지도 안의 읽기 전용 그래프에는 선택한 예시 입력의 계산값과 강조 단계를 넣었다. 이는 저장된 실주행 틱과 동일한 시간축 재생이 아니다.

## 설계 지도의 각 요소가 뜻하는 것

- **3D 차량**: 현재 선택한 단계에서 입력 센서, 제어기, 액추에이터, 기계 전달 부품의 위치를 나타낸다. 컬러로 켜지는 부품과 배선은 그 단계의 경로다.
- **Domain 선택**: 전력·구동·제동·조향 중 어떤 차량 일을 볼지 정한다. 기능 실행 순서를 뜻하지 않는다.
- **Function 선택**: 해당 Domain 안에서 직접 구성한 SW 기능을 고른다. 현재 저장된 블록 그래프가 같은 페이지에 나온다.
- **신호 따라가기**: 선택 Domain의 입력→SW 판단/계산→출력 명령→액추에이터→기계 반응을 한 단계씩 본다. 이 단계는 주행 순서를 뜻하지 않는다.
- **구현 관점 탭**: 같은 차량을 기능, 물리, E/E, SW, 검증 관점으로 보는 설명이다. 서로 다른 아키텍처 계층을 뜻하지 않는다.

## 냉정한 UX 평가와 다음 수정 순서

1. **P0 · 인과관계 시각화 깊이:** 새 단면 삽화는 선택 기능의 경계를 명확히 하지만 3D 액추에이터의 실제 기구 동작과 블록별 신호값을 한 화면에서 완전히 동기화하지는 않는다. 다음에는 하나의 물리 틱을 선택해 블록 포트 값, 해당 배선, 모터·캘리퍼·랙의 움직임을 같은 시간축에서 재생해야 한다.
2. **P0 · 기능 범위:** 직접 제작·판정하는 모델은 BMS, START, PowerEnable, DriverDemand, DriveAllow, BrakeDemand, SteeringGeometry, OutputRouting의 8개다. 열관리, 충전·12V, 회생·마찰 배분, ABS/ESC, EPS 보조, 진단·통신은 별도 계산/설명에 머무른다. 기능을 **플레이어가 만든다**고 말하려면 별도 에피소드와 요구사항·시험·저장 구조가 필요하다.
3. **P1 · 기술 선택의 실체:** 옵션 미리보기는 구성이 바뀔 때 모터·구동륜·조향·제동 경로의 차이를 보여준다. 선택한 옵션으로 실제 차를 재조립하거나 같은 차량 실행기를 다시 구성하는 기능은 아니다. 실물 선택 기능을 만들 때는 차량 변형별 부품, SW 할당, 시험 사례를 함께 바꿔야 한다.
4. **P1 · 긴 한 판:** 전력→구동→제동→조향의 4회 반복에 각 도메인의 부품 확인·장착·로직·시험이 모두 들어가 피로가 크다. 필수 도메인은 유지하되 첫 완주에서는 대표 Function 하나씩, 나머지는 차고의 추가 의뢰로 나누는 구성이 적절하다. 플레이 시간과 이탈 지점을 측정한 뒤 컷 기준을 정해야 한다.
5. **P1 · 화면 밀도:** 우측 안내의 필수 정보만 남기고 마지막 지도는 3D와 선택 그래프를 두 열에 고정했다. 1063×704에서 기술 지도와 구조 지도 세 수준의 겹침·페이지 스크롤을 확인하고 수정했다. 작은 화면, 긴 번역 문자열, 모든 게임 단계에서 내용이 잘리지 않는지 화면 검수는 남았다.
6. **P2 · 검증 학습:** 현재 시험은 기대/실제 비교를 제공한다. 단위·통합·차량 검증을 구분해 같은 결함이 어디서 발견되는지 재생하는 경험은 아직 약하다. 한 결함을 기능 블록→ECU 경계→차량 반응으로 추적하는 에피소드가 적절하다.
