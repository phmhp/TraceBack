## 이번 검증 범위

`npm test`, `npm run build`, `npm run check:independence`를 실행한다. 브라우저에서는 전체 구조 탭과 그래픽 단계가 표시되는 것을 확인했다. 로직 미션까지의 새 플레이 전체 경로와 39종 모달의 실제 작은 화면 시각 점검은 별도 진행이 필요하다. 따라서 위 표의 `코드·빌드`는 실플레이 통과를 뜻하지 않는다.
