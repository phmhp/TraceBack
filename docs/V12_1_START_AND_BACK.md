# v0.12.1 — 메인 시작하기 / 이전 단계 / 내보내기 제거

## 변경 계약

- 첫 화면은 항상 타이틀. 시작하기 버튼 하나만 표시한다. Escape로 타이틀에 숨은 설정 메뉴를 열지 않는다.
- 시작하기는 계속하기가 아니다. 현재 캠페인을 날짜별 내부 백업 키에 보관한 뒤 newCampaign의 프롤로그·40냥으로 시작한다. 백업/저장 실패 시 게임 진입을 취소한다. 오래된 READY/공방 저장 키는 새 게임 과정에서 건드리지 않는다.
- 게임 상단의 ← 뒤로, 일시정지 메뉴의 이전 단계로. 프롤로그에서 뒤로는 타이틀, 구매/시운전/사건/조사/수리/원리/퍼즐/시험은 앞 단계로, 경기 중과 시상식은 안전한 출발선으로 돌아간다. 차고에서는 시상식으로 돌아간다.
- 뒤로는 조립·그래프·지갑·차량 수집을 취소하는 undo가 아니다. 재방문 구매는 추가 차감하지 않고, 이미 조사/수리한 사건 재생은 같은 차량 기록을 유지한다.
- 원리 관찰 안에서는 앞 관점으로, 퍼즐 안에서는 앞 연결 부분으로 이동한다. 복습 중에는 현재 그래프를 그대로 표시하고 다음 부분으로 복귀한다. 과거 연결을 실제로 편집하면 그 부분 이후 완료 근거와 시험 승인을 무효화한다. 시험에서 퍼즐로 돌아가면 마지막 연결을 재확인하며 실제 연결은 지우지 않는다.
- 뒤로 이동 시 진행 중인 시험·카운트다운·들고 있는 부품·미완료 작업·키 입력을 중단하고, 차량 입력/실행기를 안전하게 재설정한다. 완료된 조립은 유지한다.
- 현재 모험의 시험 상세·차고 설계도·일시정지 메뉴 내보내기 제거. 루트의 기존 진행 내보내기/불러오기 UI도 제거. 기존 교육 자료나 엔진은 삭제하지 않았다.
- 소리/움직임 설정은 게임 안 메뉴에서 변경한다. 온라인 서비스나 원격 사이트에는 배포하지 않는다.

## 검수

- 단위 회귀 82개 통과: 새 게임/서로 다른 내부 백업/백업 실패/뒤로 경로/중복 차감·사건 재설정 방지 포함.
- 실제 React DOM 흐름: 저장된 이전 화면이 있어도 메인 Start 하나, 새 게임 두 번 모두 프롤로그, 메뉴·타이틀 왕복, 조립/퍼즐/시험/출발선의 뒤로가기와 그래프 보존. GPU mock이므로 그래픽 검수와 구분한다.
- 3D/게임 UI 렌더 회귀, 독립성 검사, TypeScript 및 프로덕션 빌드.
- 브라우저 별도 QA origin에서 프롤로그→구매→뒤로→메뉴→타이틀→새 게임을 실제 클릭한다. 1280×720 및 작은 창의 상단 버튼·제목 배치를 확인한다.
- 사용자 5175는 HMR 없는 기존 안정 서버에 최종 산출물만 반영한다. 사용자의 기존 모험을 QA 목적으로 초기화하지 않는다.

최종 실행파일 빌드 성공. 프로덕션 파일 63개가 Electron ASAR 및 5175 HTTP 응답과 바이트 단위로 일치함을 확인했다. 사용자 탭은 시작하기 하나만 표시하는 메인에 열어 두었고, 별도 QA 탭/서버는 정리했다. 화면 증빙: [메인](qa-v12-1/main-start-only.png), [뒤로 버튼](qa-v12-1/game-back-button.png), [내보내기 없는 메뉴](qa-v12-1/menu-no-export.png).

기능/그래픽 학습 범위는 v0.12와 동일하다. 기존 EXE/ZIP은 보존하며 최신 실행파일은 Vehicle-Logic-Lab-v0.12.1.exe다.
