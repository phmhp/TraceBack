# v0.10 — 흰둥의 첫 AI Playground 컵

2026-10-21. 정보 도구 세 탭을 늘리는 대신, **구동계 한 에피소드를 처음부터 보상까지 플레이할 수 있는 이야기**로 재구성했다. 독립 `vehicle-logic-lab`에서 실행하며 부모/팀원 원본은 수정하지 않았다. Sites의 로컬 검수 방식만 사용했고 외부 게시·등록은 하지 않았다.

## 플레이와 학습의 대응

| 시운전·사건 | 실제 3D START·P/D·페달·방향키, 일정 위치에서 코믹 분해 | 예정된 연출이며 운전 실수나 무작위 고장으로 채점하지 않음 |
| 관찰 | 배터리·페달을 눌러 빠진 부품/끊긴 선 확인 | 실제 assembly/cables 상태와 연결된 두 관찰 |

| 퍼즐 3 | 목표 → 변화율 → 모터 명령 | 60Nm/s = 20ms에 최대 1.2Nm. 같은 그래프에 앞 단계가 누적 |
| 시험대 | 반페달·제동 우선·신호 지연을 선택해 동작 관찰 | 실제 모델의 샘플과 독립 기대값 비교, 전체 19조건 재대조 |

〈포드 v 페라리〉는 이야기의 계기로 제목만 언급한다. 영화 영상/음악/대사와 제3자 차량·캐릭터 자산은 사용하지 않았다. 꼬마 EV와 민트 스프린터는 자체 형상이다.

## UI를 바꾼 방식

- 단계를 자유 탭으로 뒤섞지 않고 현재 사건의 다음 활동으로 이어진다. 별도 ‘내 제어로직’ 수치 도구를 주 경로에서 제거했다.
- 퍼즐은 **왼쪽 넓은 작업대 / 오른쪽 같은 차량**. 현재 세 블록만 보여 주고 앞 단계가 같은 구동계라는 경로 띠를 남긴다. 전체 내부 설정과 기술 기록은 처음부터 펼치지 않는다.
- 포트 값·수치 연산·허용 조건을 카드 안에 반영한다. 단위가 맞는 짝 강조, 클릭→클릭, 짧은 직교선, 선 클릭 해제, 실행 취소, 확대/축소, 전체 맞춤, 우클릭 배치/팬을 제공한다. 블록 이동은 작업대 경계 안으로 제한한다.
- 실차 조작은 3D 운전석에서도 가능하며 화면 버튼은 접근성 대안이다. 첫 시운전은 운전석, 대회는 바깥 시점이 기본이다. READY·기어·제동·속도 HUD가 실제 상태를 보여 준다.
- XRAY의 회전/줌/분해, 장착 부품, 페달 레버, 전력/제어 경로를 기존 3D 장면에 통합했다. 벤치에서는 차가 고정된다는 점을 명시하며, 동력선 강조를 측정 전류나 기계 회전으로 속이지 않는다. 실제 주행 중 모터/감속기/바퀴는 속도와 감속비로 회전한다.
- 작은 창에서는 겹치지 않고 세로 스크롤로 전환한다. 단일 화면 동시 비교는 데스크톱 크기에 맞춘다. 원래 흰둥는 고장 때 눈물/숙인 자세, 수리 때 렌치, 완주 때 축하 모션을 보인다. 정밀 손·공구 접촉 리깅은 아니다.

## 실행·저장·버그 방어

주행은 기존 C/WASM의 기어·인터록과 `WorkshopController`의 실제 사용자 그래프를 함께 사용한다. 60Hz 물리 실행기가 20ms 제어를 sample/hold한다. 최종 Nm가 기존 Rapier 어댑터로 전달된다. 기존 C의 VMC/eDrive를 그대로 쓴다거나 양산 EV와 같다고 주장하지 않는다. 1200kg/7:1/효율0.9/반지름0.425m 등의 교육 가정과 아케이드 제약은 v0.9 보고서를 따른다.

벤치는 같은 **논리 모델**을 별도 고정 시험으로 실행한다. 실제 주행 녹화 영상을 재생하거나 물리 결과를 독립 판정하는 기능은 아니다. 대회는 같은 graph/hardware를 실제 물리 실행기에 적용하지만 완주 기록 자체를 요구사항 검증 PASS로 부르지 않는다.

- 새 모험: `vehicle-logic-lab.momo-cup.v1`. 기존 READY/공방 키는 보존한다.
- 현재 화면도 저장한다. 퍼즐 중 재접속은 동일 단계·연결·수치, 레이스 중 재접속은 안전한 출발선이다. 의도적 타이틀 이동 외에 새로고침만으로 강제 타이틀에 가지 않는다.
- 오래된 검증 식별자는 설계 변경 시 무효화하고, 저장 로드 때 실제 요구조건을 다시 검사한다. 손상된 기록은 덮어쓰기 전에 별도 백업하며 백업 실패 시 기록을 지우지 않는다.
- 망가진 JSON/완주 기록, 미완성 부품·로직, 불일치 수치, 순환·단위 오류, 중복 상금, 경계 밖 게이트를 방어한다. 시험 중 그래프 변경은 진행 시험을 취소한다.
- 메뉴/포커스 상실 시 실제 운전 입력을 해제한다. 일시정지는 물리/카운트다운/고장 애니메이션/고정 작업을 중지한다. 벤치 시험을 일시정지했다 계속하면 해당 시험은 첫 샘플부터 다시 실행한다.
- 개발 중 5176에서 검수하고 사용자 5175는 안정 빌드로 제공한다. 마지막 배포에서만 교체하여 HMR로 사용자 플레이를 반복 초기화하지 않는다. 다음 작업도 이 원칙을 유지해야 한다.

## 재사용한 것과 범위 경계

팀원 프로젝트의 장착·고정·배선 판정과 부품 형상은 v0.9에서 내부로 적응한 코드를 재사용한다. 기존 프로젝트의 TorqueModel/독립 오라클/요구사항, C/WASM·입력·Rapier, 원래 흰둥·배경·효과음을 유지했다. 원본 폴더를 런타임에서 참조하지 않는다. 모든 과거 아키텍처 자료를 새 주 화면에 다시 나열하지 않았다. 선별 근거는 `SOURCE_CURATION_v8.md`와 `V9_INTEGRATED_WORKSHOP_REPORT.md`를 따른다.

현재 완결 범위는 **구동계 EP.01·160m 타임어택·2종 수집**이다. 두 차는 같은 교육 구동 플랫폼의 외형 변형이며 성능 모델 두 종류를 구현한 것이 아니다. 24초 고스트는 위치 기준 참고 연출이지 상대 AI가 아니다. 시동/제동/조향과 이번에 열지 않은 품질·상한 모듈은 제공된 장치로 표시한다. TC 직접 설계, MC/DC 달성, MIL/SIL/HIL 적합성, OEM/Tier1 교육 납품, 전체 EV/AUTOSAR 학습, 스위치 상용 품질을 완료했다고 주장하지 않는다.

## 다음 완결 단위

현재 엔딩은 다음 에피소드가 없는 오류가 아니라 EP.01의 차고 보상이다. 다음은 같은 차에 제동계를 누적하는 EP.02를 만든다: 레이스 속 관찰 가능한 사건 → 디스크/캘리퍼 조립 → 압력/마찰제동 퍼즐 → 정지시간·거리의 독립 기대값과 물리 결과 → 차고 제동 레이어. 이후 조향/기어, 배터리 출력 제한, 회생제동 협조 순으로 확장한다. 자세한 요청문은 `FOLLOW_UPS.md`에 있다.
