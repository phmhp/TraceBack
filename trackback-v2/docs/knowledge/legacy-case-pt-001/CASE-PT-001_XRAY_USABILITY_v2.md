# LIVE X-RAY 플레이어 중심 개편 — 구현 지시서

## 목표
처음 접하는 플레이어가 현상 → 기능 탐색 → 동일 신호의 정상 기대/실제 비교 → 요구사항 확인 → 입력 변경 시험 → 근거가 연결된 원인 제출을 수행하게 한다. 기존 C 제어 로직과 Ground Truth 원문/승인 상태는 변경하지 않는다.

## 용어와 정보 구조
- '기록'은 '주행 데이터'로 표시한다. 시간별 입력/출력/차량 위치를 저장한 데이터이며 블랙박스 영상이 아니다. 차량 화면은 저장 위치 재구성이다. 설명은 도움말에 둔다.
- 탭: 고장 현상 / 신호 비교 / 요구사항 / 재현 시험 / 원인 제출.
- 제목·범주는 굵게, 식별자·신호명은 인라인 코드로 표시한다. 차분한 엔지니어링 화면에 둥근 버튼, 미세한 음영/눌림/포커스 상태를 적용한다.
- 도움말은 탭별 행동 이유와 순서를 설명한다. 안내를 버튼처럼 만들거나 준비 완료를 반복하지 않는다.

## 화면별 변경
1. 고장 현상: '가속 페달을 밟아도 차량의 반응이 약합니다.'라는 현상을 제시한다. 이는 원인 확정이 아니다. 운전자 → 통합제어기 Application SW(POWERTRAIN) → 구동/차량 Plant 그림 안에 조사 범위를 강조한다. GearLogic / PropulsionFunction / VMC / eDrive 역할 및 조건 → 요청 → 토크 변환 → 제한 → 물리 응답 흐름을 설명한다. 제동/조향/통신은 이번 사건의 시험 범위 밖으로 명시하되 가짜 구현을 추가하지 않는다.
2. 신호 비교: 서로 다른 입력과 출력을 정상/실제처럼 나란히 두지 않는다. 선택 기능의 동일 출력에 대해 '정상 기대'와 '이번 주행'을 보여준다. 그래프도 동일 시간/입력을 적용한 기대 출력과 실제 출력을 겹쳐 그린다. 기대는 요구사항/보정값으로 계산한 기준이지 과거 정상 TC 영상이 아니다. 모델이 없는 차량 속력의 정상 궤적은 생성하지 않는다. 커서 ▼, 선택 신호의 최초 불일치 ▽, 현상 알림 시점을 구별한다. 기존 A/B UI는 제거한다.
3. 요구사항: 왼쪽 전체 작업 영역에 드래그/확대 가능한 계층 지도를 제공한다. 노드 클릭 시 오른쪽 상세 원문·관련 검증 정의가 바뀐다. 다른 탭에서도 상세는 유지한다. 선택 요구사항에 따라 적용 조건과 기대 동작 설명을 바꾸고, 가능할 때 해당 시점 입력을 함께 표시한다.
4. 재현 시험: 대상의 기능 설명 → 판단 기준 원문 → 변경 신호 선택 → 두 시험 값/고정 조건 → C 실행 결과 순서. VMC는 추진 요청 크기 또는 VehicleSpeed, eDrive는 토크 요청 크기를 조절한다. 방향 및 유효성도 선택한다. 모델 계약 범위만 허용하고 단위와 범위를 표시한다. 모든 조건을 시험 이력에 저장하고 수정 후 동일 조건으로 재실행한다. 무효 입력의 0 출력을 고장 증거로 오인하지 않는다.
5. 원인 제출: 컴포넌트/오류 유형은 플레이어 선택. 판단 기준 요구사항은 선택한 시험에서 자동 연결하며 ID와 문장을 같이 표시한다. ID 암기/수동 선택을 없앤다. '실제 출력이 어떤 기대 동작을 충족하지 않았는지'가 근거임을 설명한다. 첫 제출 및 근거 충분성 평가는 유지한다.

## 구현/검증
UI 컴포넌트와 관측용 기준 함수를 분리한다. 기준 계산은 제어 명령을 쓰지 않는다. 실제 시험은 기존 C/WASM 함수로 실행한다. 요구사항/시험 조건/출력 추적을 유지한다. 숫자 범위/NaN/잘못된 enum을 거부하고 시험 수정 후 조건 보존을 테스트한다. 타입/린트/사건 통합 테스트 및 실제 브라우저에서 지도 크기, 노드 상세 연결, 그래프, 시험 입력, 제출 기준을 점검한다.

초심자 플레이테스트와 실제 ECU/HIL 검증은 이 구현의 완료 주장에 포함하지 않는다.

## 구현 결과
- 왼쪽 대형 계층 지도에서 노드 선택 → 오른쪽 요구사항 상세 연동을 브라우저에서 확인했다.
- 같은 출력의 기대/실제 곡선과 선택/첫 불일치 마커를 적용했다. Driver Input, GearLogic, Vehicle Dynamics에는 미구현 정상 궤적을 만들지 않고 관측 전용임을 표시한다.
- 오른쪽 요구사항 선택에 따라 조건/동작 순서 및 관측 입력이 달라진다. 상세 도움말과 정상 동작 분기 그림을 추가했다.
- 재현 시험의 대상·변경 변수·두 값·방향·유효성·고정 조건을 저장한다. 실행 후 설정을 접어 결과를 우선 표시한다.
- UI 시험: eDrive 60/120 Nm → 실제 30/60 Nm, VMC REVERSE 속력 0/10 m/s(요청 0.5) → 기대/실제 65/10.833 Nm 일치. 원인 제출의 요구사항 문장 자동 연결을 확인했다.
- 타입 검사, 린트, 사건 테스트 8건 통과. 추가 테스트에는 속력 변경·후진·INVALID·입력 범위 거부 및 수정 후 동일 조건 재실행이 포함된다.
- 정상 기대 곡선은 요구사항에 따른 관측용 기준이다. 별도로 수행한 정상 TC 데이터나 물리 모델의 반사실적 재주행 결과가 아니다.
