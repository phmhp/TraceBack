# v0.15.0 검수 기록

검사일: 2026-10-22. 사용자 저장을 지우지 않는 별도 QA origin `127.0.0.1:5176` 사용.

- `npm test`: **92/92** 통과.

- `npm run test:campaign-ui`: 통과. 실제 React 이벤트/저장/진행, GPU와 고주파 프레임 입력은 테스트용 대체.

- `npm run test:click-safety`: 통과. 이전 초기화 문자열에 묶인 테스트 진입부를 새 세션 복원 계약에 맞게 갱신한 뒤 전체 검사.

단위·시뮬레이션 총 **313개**이며 교육 효과·실차·상용 품질 인증이 아니다. Three 중복 인스턴스, 일부 React act, Rapier 초기화 사용법, Rollup 큰 청크 경고는 남아 있다.

## 새 회귀와 발견한 오류

- 실제 15장치/6하네스의 6개 짧은 복구 루프, 3개의 관련 VCU 기능, 부분 조립 상태에서 첫 요청 로직 승인, 저장 복원, 다음 묶음 전환.
- 모든 이전 장착 위치→다음 픽업/장착/집 복귀 조합의 몸 반경 포함 장애물 비관통 경로.
- 실제 움직임 후 4초 자동 사건, 일시정지 시간 제외.
- 원시 Inport 존재, 블록 더블클릭, 개념 도움에서 정답 비노출/명시적 정답 지원, 같은 하단 버튼의 작은 조건 전환, 현재 샘플 Display.
- 도움 패널 아래쪽의 scrollTop=250을 만든 뒤 실행 전환 시 0으로 복원하는 회귀.
- 동일 탭 새로고침 복원 / 새 탭·명시적 타이틀의 시작하기 유지 / 이전 모험 백업.
- 앞 기능 재수정의 관련 묶음 복귀와 이후 제공 모듈, 현재 정답 비자동완성.
- 레이스 고주파 갱신 회귀: 수정 전에는 화면 상태가 누적 시간을 덮어써 결말에 도달하지 못함을 재현했다. 수정 후 60Hz 모의 프레임 320회에서 약 5.33초, 4게이트, 상금까지 실제 React 진행 통과. 물리 모의 입력 회귀이며 이 수치를 실제 160m 차량 랩타임으로 주장하지 않는다.

## 실제 브라우저 플레이

1. 일반 모션에서 구매→START/브레이크/D/가속→자동 도로 사건, 확장된 파손과 상대 차량 추월 확인.
2. 첫 회전 장치의 일반 조립 및 바퀴 앞부분 순차 장착 확인. 이후 반복 검수는 움직임 줄이기를 사용했다.
3. 6개 조립/관찰/복구, 원시 입력 포함 요청 퍼즐, 세 작은 허용 조건, 명령 퍼즐을 실제 포트 클릭으로 진행했다.
4. 미연결 모델 불일치→수정→90 Nm 실제 요청 출력, 브레이크 입력 ON→AND OFF/명령 0을 확인했다. 블록 설명 모달, 복구 누적 화면, 통합 3시험 순차 실행과 독립 전체 19조건 승인 확인.
5. 대회 완주 도우미로 시상식→140냥 지급→차고까지 진행했다. 첫 진행에서 시간 누적 버그를 발견해 수정했다.
6. 최종 수정 코드에서도 새 모험을 도움 UI 경로로 반복했다. 실제 연결 적용/검증을 건너뛰거나 저장 상태를 주입하지 않았다. 마지막 기능에서 새로고침 후 같은 모험 복원, 실행 시 블록과 Display가 바로 보이는 것 확인. 재주행 **32.0→48.9초** 누적, 4위 완주/시상/150냥 잔액/차고/완성 설계도 버튼까지 확인했다. 1위 샴페인 연출을 이번 수동 검수에서 새로 확인한 것은 아니다.
7. 1280 기본 화면, 1024×768 검사. 최종 390×844에서 문서 폭 390, 본문 bottom 728.9 / 하단 행동 top 737.9로 겹치지 않음을 확인. 작은 화면은 본문만 스크롤하며 행동 행이 독립 공간을 차지한다.
8. QA 종료 전 error 레벨 브라우저 로그 **0건**.

뷰어 렌더/동작·선택과 회전 컨트롤 연결은 확인했다. 모든 카메라 각도, 모든 손/부품 접촉, 모든 장치의 360도 회전을 수작업으로 전수 검사한 것은 아니다. Windows EXE 전체 플레이도 별도로 전수 검사하지 않았다. 실제 신규 학습자의 교육 효과/재미/도움 없는 완주 시험은 아직 아니다.
