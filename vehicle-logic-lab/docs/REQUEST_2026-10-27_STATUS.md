검증: `npm test` 108/108, `npm run test:domain-ui`, `npm run test:game-ui`, `npm run test:click-safety`, `npm run build`, `npm run check:independence` 통과. 로컬 서버 `http://localhost:5175/` 응답. 브라우저에서 설계 지도 모드 전환, 신호 단계의 실제 90 Nm 출력, 모델 진입/복귀, 엔딩→메인 복귀를 확인했다. 오래된 별도 `test:campaign-ui`는 현재 화면과 맞지 않는 ‘정답 지원 열기’ 버튼을 요구하여 실패하므로 회귀 스크립트 갱신이 남는다. 제목 원화와 3D 모델의 품질 일치, 전체 레이스 수동 플레이, 모든 카메라 관통 검사는 아직 승인하지 않는다.
