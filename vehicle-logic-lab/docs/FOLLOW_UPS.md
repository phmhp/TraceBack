다음 우선 요청: **“v0.14의 신규 사용자 동선 검수를 진행해줘. 요구사항→설계도→현재 한 연결→준비된 입력→기대/실제 출력→다음 기능을 도움 없이 이해할 수 있는지 한 단계씩 확인하고, 막히는 곳은 텍스트를 더 늘리기보다 조작/강조/작은 그래픽으로 해결해줘. 기계·전력·E/E·SW를 혼동시키지 말고 차량 전체 지도는 현재 제작 범위와 후속 도메인을 구분해줘. 같은 차량의 입력-출력 동기화, 잘못된 로직의 FAIL, 뒤로가기·저장·작은 창·실행파일을 회귀 검증해줘.”**

아트 다음 단위: 시장 서류·지불·열쇠 소품을 실제 캐릭터 손과 연결하고, 탑승/하차·손가락/공구 접촉 IK·고해상도 차량 내부 마감·음향 믹싱을 완결한다. 현재 절차적 손발/시장 장면이 상용 아트 파이프라인 완성을 뜻하지 않는다. 실제 영화 자산/브랜드 차량을 무단 포함하지 않는다.

기술 다음 단위는 같은 차량의 마찰제동 SW EP.02이며 v0.13의 후속 요청 B를 따른다. 현가 코일 표시를 능동 현가 제어 구현으로, ECU 연결을 기계 장치 대체로, EV를 곧 HPC 중앙화로 설명하지 않는다. 아래는 이전 버전 이력이다.

먼저 [요청별 반영표](V13_LEARNING_FLOW_AND_MODELING.md)를 읽는다. 브레이크 ON/OFF, 상태 도식, 15장치 실제 기록·6하네스, 왼쪽 계층 퍼즐/오른쪽 같은 차, EARS 대응 행동 요구사항, 실제 출력, 독립 시험, 5회 도움을 유지한다. 숫자 보정값 추측/직접 예측을 초급 필수 통과 조건으로 되살리지 않는다. 모모의 시범은 실제 연결 + assisted 기록이며 합격을 위조하지 않는다. 이전 문서의 필수 사용자 예상값 설명은 폐기한다.

상용 아트 패스·양손 IK·부품별 조작, BMS/충전/열관리·회생 협조, 실제 Simulink/ARXML 연동은 각각 별도 완료 기준이 필요하다. 부품을 장착했다고 해당 도메인 SW를 설계 완료한 것으로 표시하지 않는다. 아래는 이전 버전 이력이다.

운전자 화면의 `setLook` 지연 updater가 pointer-up 후 지워진 `drag.current.x/y`를 읽는 오류를 StrictMode/실제 DOM 이벤트로 재현하고 수정했다. 좌표 차이를 동기적으로 복사하고 pointer-up/cancel/lost-capture에서 정리한다. `GameRecovery`는 다른 렌더링 예외에도 공백 대신 재진입 UI를 표시하고 진행/설계 키를 삭제하지 않는다. `npm run test:click-safety`에 회귀가 있다. 추후 UI 수정 시 반드시 실행하고, 실제 GPU QA는 별도로 수행한다. 전달 범위는 루트 `HANDOFF.md`를 따른다.

### P1 — 제어기·플랜트 동일 시계 검증

> TRAINING_DRIVE_SPEC_v1.md 5절을 읽고 20ms 제어와 물리의 단일 스케줄러·명시적 단위/포트 어댑터를 설계하라. 속도·기어·이전 상태·신호 유효성의 초기조건과 입력 스케줄을 동기화하고 raw C 요청, 학습 명령, 적용 힘, 차량 응답을 같은 시간축에 기록하라. 토크/속도/거리/제동의 독립 기대 기준과 허용오차를 명시한다. 표본 seek 시 실제 물리 상태를 복원하거나 시각 replay임을 분리하라. 정상/고장/복구/회귀를 실행해 논리 PASS와 물리 PASS를 따로 판정하라. 현재 추가 상한 시연을 완전한 co-simulation이라고 이름만 바꾸지 말라.

## P3 — 문제 해결 챌린지 (P1 검수 및 READY 학습 이후)

> `engine/graph.ts`, `engine/verification.ts`, `ui/App.tsx`의 실제 실행·시험 결과를 재사용하여 READY 오류 챌린지를 추가하라. 원본 `runtime/investigation/InvestigationSession.ts`, `Evidence.ts`, `ui/investigation/`의 단서·비교 패턴을 분석해 필요한 작은 단위만 포팅하라. 실패 시험은 원인 정답이 아닌 현상 증거로 취급한다. 플레이어가 조건 누락을 관찰하고 연결을 고친 다음 동일 시험으로 통과해야 완료된다. 완료 기준: 실제 결함 주입→증거 비교→수정→재검증, 원본 보존, 검수되지 않은 ECU 정보 비노출, 신규 메뉴 실제 기능 확인 후 활성화.
