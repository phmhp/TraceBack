# v0.14.0 검증 기록

검사일: 2026-10-22. 로컬 웹 게임과 Windows portable 배포본.

## 자동 검사

- `npm test`: 86/86 통과.
- `npm run test:simulation`: 221/221 통과. C/WASM 및 Rapier 기반 회귀 포함.
- `npm run test:campaign-ui`: 통과. GPU 장면은 mock이며 실제 React 진행, 조립 기록, 작은 조건 퍼즐, 설계/실행 탭, 다음 단계 동작을 검사.
- `npm run test:game-ui`: 통과. Three 테스트 렌더러의 손-핸들 림 위치/기어 이동 회귀 포함.
- `npm run test:click-safety`: 통과.
- `npm run check:independence`: 통과.
- `npm run build`: 타입 검사 및 production 빌드 통과.

총 단위/시뮬레이션 검사 307개. 이 수치는 교육 효과나 실차 정확성의 인증 수치가 아니다. 테스트 도구의 Three 중복 인스턴스/React act 및 Rollup 큰 청크 경고는 별도로 남아 있다.

## 실제 브라우저 조작

별도 QA origin `http://127.0.0.1:5176/`에서 기존 사용자 저장 데이터를 지우지 않고 검사했다.

- 시작 → 영화 → 시장 구매/인수 → 시운전 → 도로 사건 → 도메인 조립 → 정상 모델 관찰 → 세 SW 퍼즐 → 통합 확인 → 대회 출전 그리드까지 실제 UI로 진행.
- START/브레이크/PRND 조작, 방향키 주행에서 속도 변화, 뒤로 물린 운전석과 손발/기어 반응 확인.
- 도로 사건은 이야기 바로가기 버튼으로 진입해 같은 도로와 추월 연출을 확인했다. 이번 수동 QA에서 거리 조건으로 사건이 발생하는 경로를 별도로 완주한 것은 아니다.
- 네 바퀴는 일반 애니메이션 모드에서 한 번 시작해 순차 장착되는 것을 확인했다. 나머지 조립은 움직임 줄이기를 병행해 검사했다. 15종 장착/6하네스 실제 기록 완료.
- 정상 시범의 90 Nm 출력/차량 반응, 브레이크 시범, 입력 품질과 PRND의 독립 구분 확인.
- 요청 계산 → 기어/제동/AND의 세 작은 연결 → 최종 명령 퍼즐과 준비된 상황의 실제/기대 출력 확인. 독립 19개 상황 통과 후 대회 그리드 진입.
- 도메인 수첩의 기계/에너지·E/E·SW 관점 전환 확인.
- 1280×720, 1024×768, 390×844에서 확인. 작은 화면은 순차 세로 배치되며 문서 폭 390px, 패널 겹침 없음. 퍼즐 내부의 의도된 이동/스크롤 영역은 유지.
- QA 종료 직전 브라우저 error 레벨 로그: 0건.

이번 턴에서 수동 레이스 완주/시상식 전체와 Windows EXE의 전체 플레이를 새로 확인한 것은 아니다. 낮은 프레임 환경에서도 진행은 확인했으나 60fps 보장을 주장하지 않는다. 완료한 퍼즐을 뒤로 돌아가 수정할 때 마지막 동작 확인을 다시 요구하는 기존 진행 규칙은 유지했다.
