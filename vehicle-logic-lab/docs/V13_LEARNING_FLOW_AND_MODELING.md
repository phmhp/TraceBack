# v0.13.0 — 조작 → 조립 → 모델 → 동작 확인

## 이번 변경의 기준

현재 완결 단위는 **같은 교육용 EV의 하드웨어 재조립 + VCU 전진 구동 SW**다. 정보량과 숫자 난도를 늘리는 대신, 운전자 입력이 어떤 조건/연산을 거쳐 인버터 명령과 차량 반응으로 이어지는지 단계적으로 보여 준다. 제목 화면은 시작하기 하나, 게임 안의 뒤로가기·진행 보존·메뉴 설정은 유지한다. 내보내기는 다시 넣지 않는다.

## 한 사이클의 학습

영화/첫 차 → 운전자 조작과 실제 조건 도식 → 사건 → 15종 EV 장치 소개 → 같은 차에 장착/자동 배선 → 정상 전력·회전·제동 관찰 → VCU 3개 기능 모델 → 안내된 동작 검증 → 독립 19시나리오 전체 대조 → 같은 설계로 항구 컵/시상/차고.

1. 요청 계산: 유효 페달 → Gain × K → 가용 토크 제한. 가속/해제/낮아진 가용량에서 실제 출력 확인.
2. 허용 조건: 기어 == D, 브레이크 < 해제 경계, READY, 센서 유효성의 네 조건 AND. 허용 ON뿐 아니라 READY OFF·P·브레이크·센서 불일치의 차단 확인.
3. 명령 전달: 목표 → 변화율/즉시 차단/이력 초기화를 가진 복합 Subsystem → 인버터 명령 Outport. 단순 Rate Limiter 하나와 동일하다고 설명하지 않는다.

전력선의 흐름 표시는 개념 경로다. 실제 전류/전자기장/배터리 화학을 계산한 결과라고 표시하지 않는다. 모터·감속기·축·바퀴·브레이크 움직임과 차량 응답은 기존 실행 입력/명령/물리 결과를 사용한다. 논리 판정은 독립 오라클, 실제 주행은 C/WASM+교육 제어기+Rapier이며 둘의 전체 상황이 안전성 인증된 통합 검증이라는 주장은 하지 않는다.

## 기술 표현의 출처

- [EARS — Alistair Mavin](https://alistairmavin.com/ears/): While/When/shall의 조건·응답 구조를 한국어 교육 문장에 대응했다. EARS는 수치 금지 규칙이 아니다.
- [MathWorks Subsystem](https://www.mathworks.com/help/simulink/slref/subsystem.html): 기능 묶음과 내부 모델 계층을 참고했다.
- [Compare To Constant](https://www.mathworks.com/help/simulink/slref/comparetoconstant.html): 기어/브레이크 입력과 제공 상수의 비교, Boolean 결과를 구분했다.
- [Gain](https://www.mathworks.com/help/simulink/slref/gain.html), [Saturation Dynamic](https://www.mathworks.com/help/simulink/slref/saturationdynamic.html), [Logical Operator](https://www.mathworks.com/help/simulink/slref/logicaloperator.html), [Rate Limiter](https://www.mathworks.com/help/simulink/slref/ratelimiter.html): 연산 의미 참고. MathWorks 자산이나 코드를 복제하지 않았다.

교육용 입력 source는 여러 개별 Inport처럼 표현하지만 내부 엔진에서는 한 source 노드다. 이번 허용 출력 경계도 다음 복합 Subsystem의 실제 allow 입력을 시각적으로 나타낸 어댑터다. 실제 Simulink 모델과 1:1 파일 변환을 지원한다는 뜻이 아니다.

## 이번에 끝내지 않은 범위

- 내연기관 엔진·연료·배기 해체 → EV 이식 전체 스토리/부품 세트.
- 제동·조향 SW를 플레이어가 직접 만드는 후속 에피소드, 회생제동/BMS/충전/열관리/존/HPC/AUTOSAR 구현.
- OEM CAD·캐릭터 스킨 메시/양손 IK·상용 시네마틱/성능 인증. 이번 원리·부품 시각화 개선이 Nintendo/OEM 납품 수준 인증은 아니다.
- 실제 MATLAB/Simulink 연동·.slx·ARXML·양산 ECU·HIL. 현재는 요구 동작/신호/하드웨어와 SW 경계를 배우는 자체 교육 모델이다.

## 검증 기록

- 단위/모델 85개, 복사한 시뮬레이션 221개: 별도 실행 결과는 인계에 기록.
- 실제 React DOM 캠페인 회귀: 15장치·6하네스, 3퍼즐·5회 도움, 입력 독립성, 자유 예측 없이 벤치 합격, 뒤로가기/새 시작 백업. GPU는 대역 처리한다.
- 실제 브라우저 WebGL: 시운전 조작 도식·중앙 시점·사건·15종 소개와 장착·3퍼즐·실제 출력·벤치 출전 경로, 반응형 배치를 별도 확인한다. portable EXE 패키지 일치 검사는 실제 플레이 QA와 구분한다.
- 화면 증거: `docs/qa-v13/`. 보관한 이전 EXE/ZIP은 자동 갱신되지 않는다.

다음 완결 단위는 `FOLLOW_UPS.md` 상단을 따른다. 이번 초급 조작을 다시 수치 예측 시험으로 잠그거나 별도의 텍스트 포털로 확장하지 않는다.
