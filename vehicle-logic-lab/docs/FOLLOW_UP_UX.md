# UX 후속 작업

이번 정리에서 반영한 범위: START/상태 2열 및 방향키 배열, 바깥 주행 시점, 앞·뒤 좌우 네 바퀴를 앞/뒤 한 쌍씩 한 동작으로 장착, 부품 역할 안내, 조립 이후 배선·카울을 먼저 마치고 시스템 연결, 연결 시범 단일 행동, 선택 블록·연결선 Delete/Backspace 삭제, 실제 요구 조건과 다음 조작 안내, 자동 주행, 결승 3·2·1 카운트다운, Subsystem 내부 그래프와 경로 이동, 기능 트리, 3D 차체/내부/분해 관찰, 신호→액추에이터 단계 재생 및 완료 후 차고 전시 종료. 기본 글꼴은 로컬 Pretendard이며 차량 외장·차대의 색을 맞췄다.

다음 검토는 별도 사용자 테스트 후 진행한다.

- 참조 이미지의 Simulink 라이브러리 전체를 동일 기능으로 구현하는 작업은 별도 엔진 설계가 필요하다. 현재 검증 엔진은 교육 미션의 10종 블록과 동작 보존형 Subsystem을 실행하며, 미션별 필요한 블록만 팔레트에 노출한다. 다른 참조 블록을 동작하지 않는 장식 버튼으로 노출하지 않았다. 후속 프롬프트: `From/Goto, Sum/Product, Bus, Lookup Table, Delay/Memory, Data Store, Mux/Demux, Switch, Chart 등 각 블록의 타입·포트·시간 상태·테이블 파라미터를 정의하고 독립 단위 테스트를 작성한 다음 전체 팔레트에 노출해줘. 현재 미션의 정답·저장 호환성을 유지해줘.`
- 충돌 시 파편 바닥 관통과 주행 카메라 떨림을 완화하고 마지막 얼굴 클로즈업·슬픈 표정, 반원형 앞/뒤 유리, 같은 청록 차체, 조립 위치 보정 등을 반영했지만 제목 원화 수준의 3D 모델·리깅·재질 품질에 도달했다고 주장하지 않는다. 후속 프롬프트: `TRACKBACK 고유 캐릭터와 차량 모델을 보존하면서 제목 원화의 차량 실루엣·고양이 얼굴을 3D 전용 자산으로 재제작하고, 창문/시트/키/부품의 관통을 전 컷에서 카메라별로 검사해줘. 얼굴 표정 리그, 차체 파손 및 복구 모션, 도로·실내 재질·광원, 느린 장치 성능을 함께 검증해줘.`
- 배선·카울 마무리는 현재 순서와 진행 표시 및 3D 카울 이동으로 표현한다. 케이블별 실제 체결 동작은 아직 개별 애니메이션이 아니다. 후속 프롬프트: `배선 6개를 각각 포트에 연결하고 카울 체결을 마지막으로 재생하는 조립 애니메이션을 구현해줘. 시스템 로직 단계는 모두 끝난 뒤에만 열어줘.`
- 작은 화면에서 로직 블록의 긴 이름과 완성 차량 지도를 직접 점검하고, 필요하면 축약명/툴팁/반응형 레이아웃을 추가한다.
- 결승 코스 랜덤화와 다차원 순위 AI는 현재 고정 경로의 결정적 검증을 깨지 않도록 별도 모드로 추가한다. 후속 프롬프트: `시드 기반 3개 코스 변형을 만들고 각 코스의 출발/게이트/도착 판정, 경쟁 차량 동시 출발과 재시작 재현성 테스트를 추가해줘.`
- [아키텍처 관점·구현 범위 결정](ARCHITECTURE_DECISION_2026-10-27.md)을 기준으로 ‘필수 차량 기능 모두 만들기’를 후속 에피소드로 확장한다. 현재 6개 Application 기능을 전체 EV 기능이라고 표시하지 않는다.
- 예전 `scripts/check-campaign-ui.mjs`는 현재 레거시 화면에 없는 ‘정답 지원 열기’를 요구해 실패한다. 후속 프롬프트: `레거시 MomoCampaign의 현재 도움말 동선에 맞춰 check-campaign-ui.mjs를 갱신하고 GPU 모킹의 검증 범위/실제 화면 검증을 분리해줘. 기존 TRACKBACK 데이터를 바꾸지 마.`
