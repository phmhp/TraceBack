## 실제 브라우저 확인

분리한 검수 포트 5176에서 WebGL 화면/실제 DOM으로 다음을 확인했다.

- ON/OFF → START → D → OFF, 실제 상태로 채워지는 도식과 중앙 바깥 시점.
- 사건 장면, 15종 부품 소개, 첫 모터의 기본 운반·장착 완료와 나머지 접근성 모드 조립, 15/15 완료.
- 실제 포트 클릭 두 번 연결, 5회 실패 후 자동 해설과 다음 연결 시범, 3개 기능 검사 및 결과 출력.
- 숫자 직접 예측 없이 안내 시험 3개를 완료해 전체 독립 기준 대조 후 대회 출전.
- 대회에서 방향키 가속에 따른 실제 속도 증가. 이번 수동 검수에서는 대회 완주/시상식을 끝까지 재플레이하지 않았다. 동일 그래프의 C/Rapier 코스 완주는 자동 모델 검사로 별도 통과했다.
- 1280×720, 1024×768, 390×844 퍼즐 배치. 390px에서 documentWidth=390, 결과/다음 버튼이 겹치지 않고 세로 스크롤로 접근한다. 퍼즐 자체의 좌우/상하 작업 공간 스크롤은 의도된 기능이다.
- 느린 프레임에서 시험 재생이 길게 지연되는 문제를 수정했다. 물리 주행은 실제 프레임/장치 성능에 영향을 받으며 60fps/상용 기기 성능 인증은 하지 않았다.
