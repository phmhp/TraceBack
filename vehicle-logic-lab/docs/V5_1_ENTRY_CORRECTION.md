# v0.5.1 — 시작 흐름 정정

사용자 요청: 새로 제작한 게임을 계속 사용하되 고양이는 원래 캐릭터로 유지한다. 기존 TRACKBACK 본편으로 연결하는 것은 요청이 아니었다.

- 시작 화면의 CampaignHost import/state/전환을 제거했다. 새 모험은 기존 `start()`의 운전자 시점 인트로로 시작한다.
- 새 게임의 인트로, 정비소, 차량 내부 탐험, 단계별 조립, 시험, 보상, 저장 형식을 변경하지 않았다.
- 이미 복원한 원래 고양이 PNG 및 같은 캐릭터의 정비소 원화를 유지했다. 새 이미지를 생성하지 않았다.
- 기존 `simulation/` 소스·자료·별도 엔진은 삭제하지 않았다. 새 게임의 기본 진입 경로에서는 사용하지 않는다.
- 주행·아키텍처 확장을 별도 앱 진입으로 대체하지 않는다. 새 게임 내 단계적 체험으로 확장하는 작업은 이번 캐릭터/진입 정정에 추가하지 않았다.

검증: `npm test` 27/27 통과, `npm run build` 통과, `npm run check:independence` 통과. 개발 서버의 게임 모듈이 HTTP 200으로 「새 모험 시작」을 제공하고 CampaignHost를 포함하지 않음을 확인했다. 진입점 회귀 테스트는 소스 계약 검사이며 실제 브라우저 클릭 검증과 구분한다.

추가 확인: 타이틀·원래 고양이 컴포넌트의 서버 렌더링 계약 통과. 개발 서버 새 게임 의존 파일 30개 응답 오류 없음. Windows 패키지의 app.asar 내 dist 파일 54개가 현재 빌드와 바이트 단위로 일치하며 버전 0.5.1과 새 게임 진입 문구를 확인했다. 실제 브라우저 상호작용 검증은 미완료다.

실행: `http://localhost:5175/`에서 「새 모험 시작」 또는 기존 저장이 있으면 「모험 이어하기」. Windows 새 배포 파일은 `release/Vehicle-Logic-Lab-v0.5.1.exe`.
