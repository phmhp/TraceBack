# v0.8 — 차량 위에서 동작을 따라가는 학습

## 실제 변경

- 별도 정보 포털 대신 메인 모험 수첩에 6개 기능의 시각적 지도를 통합했다. 기능 관계 지도이지 실제 ECU 배치/물리 배선도가 아니다.
- READY 0/3과 원래 고양이를 유지했다. 현재 위치를 차량 → 차량 상태 → READY → 현재 하위 부분으로 표시한다. 다음 연결은 다른 기능으로 이동하는 것이 아니라 같은 READY 기능을 완성하는 과정이다.
- 같은 EV 플랫폼에서 페달 회전, 센서 반응, 제어기 덮개 열림, 신호 이동, 구동 허용을 관찰한다. 주행에서는 실제 물리 속도로 바퀴가 회전하고 앞바퀴 명령 각도가 반영된다. 모터 회전은 바퀴와 연결한 교육용 기구 표현이며 실제 RPM 측정이 아니다. 배터리는 형상만 있고 SOC/전류 계산이 없다.
- 기어·구동·제동·조향 지도에는 정상 기준 실행기 시연이 있다. 제공된 기준 모델이며 내 설계 완료와 혼동하지 않도록 표시했다. C/TS 명령과 Rapier 응답을 구분한다.
- 작업대의 차량과 로직이 같은 Snapshot을 쓴다. 정상 시나리오 따라가기는 실제 사용자 그래프를 실행한다. 기대 상태/출력과 실제 결과를 비교하며 정답 애니메이션을 재생하지 않는다.
- 퍼즐 공간 확장, 휠 줌, 전체 맞춤/100%, 우클릭 제목 드래그(블록), 우클릭 빈 곳 드래그(화면), 포트 클릭 두 번 연결을 제공한다. 안내식 퍼즐의 배치는 화면용이고 단계 이동 시 초기 배치로 돌아간다. 전체 자유 편집기의 좌표는 설계에 저장한다.
- 시험 단계의 예측 답변 관문과 ‘검증자의 모자’ 표현을 제거했다. ‘제공된 정상/변경 조건과 내 로직 대조’가 학습 목표다. 실제 TC 저작이나 시험 설계 기법 교육을 완료했다고 주장하지 않는다.
- 구동 수치 로직 제작을 같은 게임 지도와 진행 화면 안에 넣었다. READY 허용이 실제 주행 게이트이며 수치 설계의 READY 체크만으로 이를 우회하지 않는다.
- AUTOSAR는 선택 설명, 미구현 영역은 명확한 참고 표시로 남겼다. [자료 선별 근거](SOURCE_CURATION_v8.md).

## 검증과 근거

자동 테스트: 게임/엔진 56개, 복사된 시뮬레이션 221개. DOM 이벤트 검사는 빠른 시야 드래그/해제, 지도 진입, 구동 제작, 우클릭 블록 이동/팬, 작업대 확장, 보존된 참고 자료 539개 선택, 오류 복구와 저장 보존을 다룬다. GPU는 DOM 검사에서 대역 처리한다. 별도 3D 계약 검사는 페달·덮개·회전·일시정지를 다룬다.

실제 IAB 창(1063×704)에서 지도, 탐험 3단계, 작업대/확장 작업대, 구동 기준 모델 시연을 직접 확인했다. 이 창에서 가로 문서 넘침은 없었고 오른쪽 추가 정보는 내부 스크롤로 접근한다. 브라우저 viewport 변경 기능이 실제 창 크기에 반영되지 않아 다른 해상도를 실제 검수했다고 기록하지 않는다. 화면 근거: `screenshots/v8-map-1063.jpg`, `screenshots/v8-workbench-1063.jpg`, `screenshots/v8-workbench-expanded.jpg`, `screenshots/v8-propulsion-live.jpg`.

독립성 검사와 TypeScript/프로덕션 빌드를 수행한다. Windows portable은 최신 dist와 ASAR 내 파일 바이트 일치/필수 자원 검사를 수행한다. 이는 EXE에서 전체 모험을 수동 완주했다는 뜻은 아니다.

최종 확인: 277/277 통과, DOM/3D 계약 검사 통과, 독립성 검사 통과, 빌드 성공. v0.8.0 EXE 생성 완료. 최신 ASAR의 dist 58개 파일 바이트 일치와 개발 서버 모듈 115개의 HTTP 200을 2회 확인했다. 실제 제동 시연에서 60% 입력과 3900N 명령, 감속 후 정지를 확인했다. DOM 검사에는 Three 중복 import 및 비동기 상태 갱신 act 경고가 남아 있다. 테스트 실패나 실제 브라우저 예외는 관측하지 않았으나 경고가 없는 테스트 환경으로 주장하지 않는다.

## 남은 범위 — 과장하지 않기

- 제작/채점은 READY와 수치 구동 모듈 중심이다. 6개 지도 섬이 6개 완성 제작 미션을 뜻하지 않는다.
- 수치 모델은 20ms 단위 실행/독립 19개 시험을 제공하지만, 주행 결합은 UI 샘플링 기반의 기존 C/Rapier 추가 토크 상한 시연이다. 동일 시계의 완전한 제어기/물리 통합 검증이 아니다.
- 실제 주행은 짧은 시험 트랙이다. 완성된 레이싱 캠페인·대규모 자동차 시스템·OEM 인증 도구가 아니다.
- 외형 배치는 교육용이고 실제 차종의 패키징·유압·모터 전자기·배터리 열/전기 모델은 없다.
- 실제 RPM·ActualDriveTorque 센서 생산자는 없다. 그래픽 모터 회전을 독립 측정값으로 취급하지 않는다.
- 화면 복구는 예외 발생 때 저장을 지우지 않는 안전망이지 모든 UI 오류가 없다는 보증은 아니다.

다음 우선순위는 정보 추가보다 같은 시간축의 입력→로직→힘→응답 기록, 기어 인터록/제동 우선의 정상 요구사항 제작 미션, 그 뒤 관찰 증거에 기반한 사건·수리·같은 조건 재주행이다. 제품 방향의 Phase A(조사 의미)→B(의뢰/단서)→C(캐릭터 반응)→D(수리/재주행)→E(보상)를 지킨다.
