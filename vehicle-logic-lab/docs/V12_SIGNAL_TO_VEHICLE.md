# v0.12.0 — 신호에서 차량 반응까지

## 이번 완결 단위

전진 구동 한 기능의 **장치 조사 → 복구 → 정상 원리 관찰 → SW 모델 → 신호 시험 → 실제 주행**을 연결했다. EV 전체를 완성했다고 표현하지 않는다. 기존 학습 구조와 저장 키, 보상, 구버전 실행파일을 유지한다.

### 무엇을 공부하는지

- 조사/조립: 선택한 부품 이름, 전력/센싱/전자제어 도메인, TRAY/SEATED/FIXED 상태를 차량 아래 고정 영역에 표시한다. 선택 부품에도 3D 라벨, 장착 자리에는 반투명 윤곽 설명을 붙인다.
- 조립 옆 그림: 배터리 DC 전력, 센서 값, VCU 토크 명령, 인버터 AC 전력을 구분한다. 고정/배선 상태가 실제 저장과 함께 성장한다.
- SW: 구동 요청 계산 → 구동 인터록 → 명령 동특성. 제동 인터록은 마찰 제동 로직 제작이 아니라고 명시한다.
- 시스템: 센서–VCU–인버터–차량의 전진 구동 통합을 마지막 시험에서 확인한다. 다른 도메인이 아직 없는데 차량 전체 통합 완료라고 도장 찍지 않는다.

## 실행 모델 변경

기존 7블록 permit 연산을 9블록으로 확장했다. `input.gear`는 P/R/N/D enum이며, gearCompare가 설정된 상수와 실제 비교한다. brakeCompare는 BrakePct와 설정된 경계를 비교하고, all은 센서 정상/READY/전진/제동 미개입 네 Boolean이 모두 true일 때만 허용한다. 비교 상수와 임계값을 바꾸면 실행 결과와 독립 시험 판정이 실제로 달라진다.

Gain의 `Nm/%`, 차단 경계 `%`, 변화율 `Nm/s`는 **설계/보정 파라미터**다. 페달 50%, BrakePct 4.99%, GearState=D는 **시험 자극값**이다. 보정 패널을 접어서 구분하고, 식·단위·교육 사양을 설명한다. 페달 50%를 모든 정상 운전의 기본값처럼 강요하지 않는다. 1.8Nm/% 선형 변환은 이 교육용 가상 사양이지 실제 EV의 보편적 맵이 아니다.

불완전한 설계에서도 안전한 상류 신호는 관찰할 수 있지만, 구조 오류가 있는 명령은 0으로 차단하고 상태를 초기화한다. 기존 7블록 자유 공방은 유지한다. 과거 캠페인 저장은 기존에 연결돼 있던 permit 선만 비교 블록으로 확장한다. 빠져 있던 플레이어의 선을 정답으로 채우지 않는다. 정상 검증된 옛 승인은 새 그래프의 동작을 재검증한 뒤 해시를 갱신한다.

## 입력과 검증

- 가속/제동 슬라이더, 꾹 눌러 증가, 손을 떼면 값 유지, 0 버튼으로 해제. READY는 ON/OFF, 기어는 enum 선택.
- 상세 입력: 채널 B, 신호 나이, 가용 상한. 모델 입력에 직접 인가하므로 시험대에서 운전자 페달 스무딩을 입력값으로 오해하지 않는다. 실제 도로 주행에는 원래 DriverInputRuntime이 유지된다.
- 사용자 시험: 명령 0으로 초기화하고, 현재 신호 조합을 4초 동안 고정 인가한다. 학습자는 최종 토크를 예상한다. 실제와 기대는 20ms마다 계산하며, 기대는 `torqueSpec.ts`의 독립 oracle이 소유한다.
- 세 곡선: 페달 A(0–100%), 기대 토크(0–180Nm), 실제 토크(0–180Nm). 축 범위를 범례로 구분한다. 모든 인가 신호와 현재 기대/실제를 텍스트로도 표시한다.
- 출전 전 기본 3시험 + 직접 만든 시험 1회 + 출력 예측 일치를 요구한다. 나머지 19조건 회귀 대조도 유지한다. 이것만으로 TC 설계 기법 전체나 OEM 교육 자격을 획득한 것은 아니다.
- 입력/기대/실제 샘플, 요구사항, 모델 해시, 사용자 예측을 JSON으로 내보낸다. 사용자 임의 시간 시퀀스 편집·CSV 가져오기·MC/DC는 후속이다.

## 그래픽/인터랙션

- 모모 다리 길이를 줄이고 몸통·발을 둥글게 수정했다. 오리지널 얼굴/귀는 보존했다. 차체 바깥 왼쪽 통로의 지상 경로로 이동한다.
- 조립 대상 부품은 작업대에서 실제 손 좌표로 옮겨지고, 마지막에 장착 슬라이드로 이동한다. 복제 부품을 따로 들고 있는 방식은 제거했다. 고정 시 손–볼트 연결 공구를 표시한다. 과장된 보조 슬라이드/연장 공구이며, 실제 역기구학 손가락 그립이나 정밀 접촉 물리는 아니다.
- 반복 케이블 구슬 애니메이션을 제거했다. 전력선은 전선으로 남고, 페달 레버/모터 로터/감속 축/바퀴/브레이크 패드의 동작은 실행값을 사용한다. DC/AC 전류 파형이나 전자기 해석은 구현하지 않았다.
- 배터리 확대의 시험 전원 스위치는 실제 3D 클릭 대상이며 READY와 연동된다. 교재용 장치로 명시한다. 현실의 HV 배터리에 사용자가 임의로 스위치를 조작하라는 정비 지침이 아니다.
- 구동계 지도 노드를 누르면 설명이 지도 안에서 열리고, 필요할 때 같은 3D 차량 위치로 이동한다.
- 가상 경쟁자 루루/보리/토토는 서로 다른 가속/도착 시간 프로필로 같은 코스에 표시된다. 위치/시간으로 순위를 계산하고, 결과는 1위 트로피·그 외 완주 메달로 구분한다. 1위에는 무알코올 스파클링 연출을 표시한다. 온라인 사용자, 학습형 AI, 경쟁 차량 충돌은 없다.

## 재사용과 기술 경계

기존 팀원 기반 부품/프레임 모델, TRACKBACK 고양이, C/WASM 기어 로직, Rapier 주행, torqueSpec 요구사항/19조건, 기존 클릭 연결/확대/우클릭 이동을 재사용했다. 부모 프로젝트 및 팀원 원본 파일은 수정하지 않았다.

현재 Plant는 간단한 구동/제동 교육 모델이다. 특히 물리 어댑터는 0보다 큰 제동에 구동 힘을 억제하는 기존 규칙을 쓰며, SW의 BrakePct=5% 차단 경계와 동일한 정밀 제동 검증 모델은 아니다. SW 경계의 정확한 판정은 파형 시험이 담당한다. 전기/유압/BMS/SOC/회생제동/CAN/AUTOSAR 실행/HPC 배치 전체가 구현됐다고 주장하지 않는다.

기본 주소: `http://localhost:5175/`. 개발 서버 5176과 분리한 생산 미리보기라 개발 저장 때 사용자 게임이 반복 리셋되지 않는다. 임시 스냅샷에 과거 해시 자산도 보존하여 기존 탭의 지연 로딩을 보호한다. 사용자의 브라우저 저장은 새 시험용 loopback 주소와 분리했고 지우지 않았다. 사용자 탭을 새 버전으로 한 번 다시 연 뒤 기존 **출발선/10냥/검증된 설계**가 복원됐고, 새 생산 페이지의 오류 로그는 0개였다. 개발 QA 탭과 서버만 정리하고 기본 주소는 실행 상태로 남긴다.

Windows x64 실행파일: `release/Vehicle-Logic-Lab-v0.12.0.exe`, **133,086,182 bytes**. SHA-256: `291d7cb4064368be03aa5dc43d87ac443955def784f6094b4427c0d8d039ab3a`. 배포 ASAR의 dist **64파일**이 최종 빌드와 바이트 단위로 일치한다. 실제 플레이는 브라우저에서 검수했으며 휴대용 EXE 자체의 전체 수동 플레이를 수행한 것은 아니다.
