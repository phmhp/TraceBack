## 기술 방향
이 게임은 주행 핵심 부분 모델이다. 기능 분해와 구현 관점은 다른 축이다. 도메인별 제어기/VCU를 단순화한 도메인 지향 E/E를 선택하며 zonal·실제 AUTOSAR RTE/BSW·HIL·양산 검증 구현이라고 주장하지 않는다.
