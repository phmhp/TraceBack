# v0.6 — 새 게임의 직접 주행과 차량 반응

## 1. 구현 완료

- 기존 본편으로 전환하지 않고 새로운 게임 안의 Canvas에 보존된 차량 런타임을 조합했다.
- 운전석에서 화면 드래그로 좌우/아래 시야 이동. 정면·페달·기어 프리셋과 차량 바깥 카메라를 제공한다. 아래를 보고 3D 페달을 누르거나 기어 레버를 누를 수 있고, 화면 페달 및 P/R/N/D도 사용한다.
- 방향키/WASD 가속·제동·조향. C/WASM이 토크/기어를 계산하고 Rapier ray-cast 차량이 중력·접지·주행·충돌을 계산한다. 속도·토크·페달 압력을 실제 텔레메트리로 표시한다.
- 오프닝은 자동 이동 사진이 아닌 75m 직접 주행이다. 이동 거리 도달 뒤 부품이 튀고 차체가 주저앉으며 원래 고양이가 눈물을 흘리는 3D 스크립트 연출로 이어진다. 이는 예정된 장난감 차량 연출이지 운전자 실수로 발생한 현실 사고나 고장 원인의 설명이 아니다. 주행 건너뛰기도 유지했다.
- 시동 준비, 변속, 분해 효과음과 속도·가속 입력을 따르는 작은 합성 EV 모터음을 추가했다. 음량 0을 지원한다.
- READY/drive와 그래프 오류 유무를 실제 C 입력에 연결했다. 1장 request만으로 구동하지 않는다. 정상 관찰에서는 기준 로직, 작업대·시험·보상 주행에서는 학습자 로직을 사용한다. 정상 관찰에서 물리 브레이크 입력을 Boolean 조건에 연결하고, 실제 속도 0.5km/h 미만을 교육용 정지 판정으로 읽는다. 시험 스위치도 별도로 표시한다.
- 요구사항과 정상 흐름을 작업대·시험에 표시한다. 자체 가상 READY 사양을 사용하며 독립 기대값을 변경하지 않았다.
- 큰 포트, 논리 기호, 종류별 블록, 굵은 케이블·그림자·화살표·활성 펄스, 연결 가능한 짝 강조. 클릭 두 번은 입력부터 시작해도 된다. 드래그 연결, Esc 취소, 선 선택·제거, 되돌리기를 지원한다. 연결은 기존 타입/순환 검사를 그대로 거친다.
- 차량 탐험은 전체 부품 간 흐름과 개별 분해 보기, 부품↔논리 신호↔SW↔차량 출력, SW 입력/조건/에지/상태/출력 하위 구조를 제공한다. 값은 현재 Snapshot을 표시한다.
- 기존 차량 자료 탐색기를 새 게임 내 선택형 오버레이로 재사용했다. 별도 추리 앱으로 이동하지 않는다.
- 테스트는 실제 그래프를 입력 단계별로 다시 실행해 신호·상태·부품과 물리 차량을 보여준다. 마지막 SW 출력에서는 제동을 해제하고 일정 가속을 넣어 구동 허용/차단을 관찰한다. 최종 판정은 독립 요구사항에 따른 기존 엔진 결과이다.
- 검증 후 2/3장 보상 화면에서 내 READY 출력으로 직접 재주행한다. 1장은 상태 변경 없이 요청만 계산하므로 부품 반응만 제공한다.

## 2. 기존 자산 재사용

독립 폴더의 `simulation/`에 보존된 SimulationRuntime, WasmVehicleSw, RapierVehiclePhysics, 기존 캘리브레이션, 원래 CatDriver 및 입체 차량을 재사용했다. 원본 `trackback-v2/` 및 루트 앱은 변경하지 않았다. 기존 정비소 원화·차량 투시 원화·고양이 PNG·부품 모형을 유지했다. 이번 작업에서 새 이미지 생성이나 제3자 캐릭터 복제는 하지 않았다. 참고 이미지는 클릭/케이블 조작의 직관성만 참고했다.

## 3. 주요 변경 파일

- `src/game/DriveExperience.tsx`, `driving/`: 새로운 게임 내 물리 Canvas, 시점, 조작, C 구동 게이트.
- `CockpitV4.tsx`, `FaultCutscene.tsx`, `Game.tsx`, `audio.ts`: 실제 주행 진입, 사건 연출, 반응음, 보상 재주행.
- `ConnectionBoard.tsx`, `interaction.ts`, `ui/LogicEditor.tsx`: 클릭/드래그 연결 및 블록 가독성.
- `VehicleExploration.tsx`, `ArchitectureExplorer.tsx`, `RequirementBrief.tsx`: 물리/논리 층과 요구사항.
- `TestReplay.tsx`: 실제 실행 추적과 별도 물리 시연.
- `experience.css`: 밝은 새 조작/주행/자료 UI.
- 복사본 `simulation/src/runtime/SimulationRuntime.ts`: 선택형 READY 게이트. 미설정 시 기존 동작 유지. C 입력 기록과 표시도 게이트 후 값을 사용한다.
- 복사본 `KnowledgeAtlas.tsx`: 새 게임의 전체 참고자료 모드 옵션. 기본 구동 사건 모드는 보존했다.
- `tests/experience.test.mjs`, `scripts/check-new-game-ui.mjs`: 새 동작과 렌더링 계약 검사.

## 4. 검증 결과

- 새 게임 자동 테스트 32/32: 기존 READY·오라클·저장, 시야 범위, 포트 양방향 클릭, 신호 타입 거부, 실행 추적과 공식 판정 일치, C 구동 게이트, 실제 Rapier 가속·조향·제동·후진·일시정지.
- 보존한 시뮬레이션 회귀 221/221: 정식 엔진·기어·물리·신호·조사 의미·자료 관계·시험/수리 경로 보존.
- 별도 `npm run test:game-ui`: 메인 진입·큰 포트/블록·요구사항 렌더링, 3D 페달/핸들 회전, 3D 페달 press/release 이벤트, 부품 분해 애니메이션과 일시정지 계약 통과. 이 검사는 GPU 화면 캡처가 아닌 테스트 렌더러 검사다.
- `npm run build`, `npm run check:independence` 통과. Windows portable 0.6.0 생성 완료. app.asar의 dist 파일 56개가 현재 빌드와 바이트 단위로 일치했다. 개발 서버의 새 게임 모듈 84개를 두 차례 조회해 응답 오류가 없음을 확인했다.
- 브라우저 제어의 기존 정책 차단 때문에 실제 화면 클릭·해상도별 시각 검사·실행파일 전체 플레이는 미완료다. 위 자동 검사를 실플레이 완료로 표현하지 않는다.

## 5. 그래픽 범위

기존 자체 아트의 밝은 청록/블루/화이트 팔레트와 반투명 UI를 유지했다. 운전석·차량·주행 배경과 사건은 런타임 3D, 정비소와 차량 위치도는 기존 원화이다. 정비소 전체가 실시간 이동 가능한 3D 공간으로 바뀐 것은 아니다. 사고는 리깅 기반 전용 컷신이 아닌 기존 차량 부품의 procedural 분해 애니메이션이다. 원래 고양이의 크림색 몸·검은 눈과 자산을 보존했다. 원화와 완전히 같은 전용 운전석/차량 모델, 정식 표정 리그, 곡선 트랙의 환경 미술은 후속 품질 작업이다.

## 6. 자료 검수 상태

기존 539개 엔티티·2,195개 관계의 출처와 DRAFT/DESIGN_ONLY/AI_DRAFT 상태를 유지했다. 새 게임의 READY 기능 분해는 명시적인 가상 사양이다. 차량 참고자료를 READY 채점 정답으로 전환하지 않았고 OEM 적합성·ISO 인증·HIL 검증 완료를 주장하지 않는다. 구동 캘리브레이션은 기존 SIMULATION_ASSUMPTION/REVIEW_REQUIRED 게임 조정값이다.

## 7. 남은 범위

- 테스트 리플레이의 SW 입력은 원본 시나리오를 재실행하지만 물리 차량의 초기 속도·움직임 전제까지 모든 시험에서 동기화한 것은 아니다. 화면에서 이 차이를 고지했다. 물리 시연의 이동 여부를 READY 논리 시험 판정으로 사용하지 않는다.
- 현재 직접 제작하는 콘텐츠는 READY 3장이다. 가속·제동의 C 실행을 재사용하는 것과 그 로직을 새로 제작하는 챕터는 다르다. 숫자 블록/토크 제한/제동 제어 콘텐츠는 미구현이다.
- 직접 주행은 밝은 직선 시험 구간이며 완성된 서킷 레이스/랩타임 캠페인이 아니다.
- 접근성/키보드와 마우스 동시 조작/카메라·패널 겹침/게임패드/초기 WebGL 로딩은 실제 플레이 QA가 필요하다. 정식 게임패드는 이 새 조작 화면에는 아직 연결하지 않았다.
- Windows 파일은 서명되지 않은 개발용 portable 빌드다. 구버전 파일과 저장을 삭제하지 않는다.

## 9. 실행

브라우저 `http://localhost:5175/`에서 새로고침 → 새 모험 시작. 시야 드래그 또는 페달/기어 보기, 출발, 방향키로 75m. 사건 뒤 정비소에서 단계별로 진행한다. 기존 저장은 모험 이어하기로 유지한다. Windows `release/Vehicle-Logic-Lab-v0.6.0.exe`는 구버전 창을 닫고 실행한다. F11 전체화면, Esc 메뉴. `npm test`, `npm run test:simulation`, `npm run test:game-ui`, `npm run build`, `npm run check:independence`로 자동 검사를 재현한다.
