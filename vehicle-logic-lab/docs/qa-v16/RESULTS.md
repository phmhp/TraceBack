새 시작 → 시장 계약 → 주행/파손 → 앞/뒤 휠 세트 → 네 도메인의 운전자 경험/부품 묶기/개별 장착/퍼즐/동작 판정 → 시스템 연결 → 배선/카울 → 실제 주행 시험 → 160m 대회 → 시상식 → 완성 지도까지 한 사이클을 수행했다.

- 전력에서 OR 오답을 직접 구성해 READY 없는 경우 잘못된 TRUE를 확인하고 AND로 수정, 4/4 통과.

- 블록 설명, 확대/전체 맞춤/큰 작업대, 실제 출력 Display와 개별 장치 동작, 4200N 제동·정차를 확인했다.

- 지도/로직 다시 보기와 완주 기록의 새로고침 복원 확인. React 검사에도 마지막 지도 재마운트 후 6개 모델/기록/지도 보존을 추가했다.
- 시험 중 길 옆에 걸렸을 때를 위해 ‘출발 위치로 · 확인한 기능 유지’를 추가했다. 차만 되돌리며 미완료 시험을 통과시키지 않는다. 해당 동작은 React 회귀 검사에 포함했다.
