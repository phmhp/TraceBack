## 최신 전달본 — v0.12.1 · 시작과 뒤로가기

메인은 **시작하기** 하나만 표시하며, 저장 기록이나 이전 화면에 관계없이 타이틀에서 시작한다. 시작하기를 누를 때마다 프롤로그의 새 게임을 만들고 기존 모험은 내부의 날짜별 백업 키에 보관한다. 백업에 실패하면 기존 진행을 덮어쓰지 않는다. 타이틀에서는 설정·이어하기·자유 연습·내보내기를 표시하지 않는다. 설정은 게임 안의 메뉴에서 사용한다.

게임 상단 **← 뒤로**와 메뉴의 **이전 단계로**로 앞 장면을 다시 볼 수 있다. 퍼즐 안에서는 앞서 만든 연결 부분을 복습하며 현재 배선을 유지한다. 조립 상태·자산·상금은 뒤로가기로 취소되지 않는다. 이미 구매한 차는 재구매하지 않으며 사건을 다시 봐도 수리·설계가 초기화되지 않는다. 시험에서 퍼즐로 돌아가 실제로 수정하면 검증 근거는 재확인한다. 현재 모험의 시험·차고·메뉴 및 타이틀의 진행 내보내기/불러오기는 제거했다.

## 최신 전달본 — v0.12.0 · 신호에서 차량 반응까지

XRAY 선택 부품의 이름·도메인·장착 상태를 크게 표시한다. 모모는 짧은 다리 비율로 수정했고, 차체 바깥 경로로 이동한다. 운반할 때 실제 부품 하나가 손 위치와 장착 슬라이드를 따라 이동한다. 고정 공구는 볼트 위치까지 이어진다. 완전한 손가락 IK나 리깅 아트 완성을 뜻하지는 않는다.

구동 허용 퍼즐은 **GearState == D / BrakePct < 경계 / 네 조건 AND**를 각각 실행하는 9블록 모델이다. 설계 보정값과 시험 입력을 분리했다. 입력은 연속 페달 게이지, READY 스위치, 기어 선택으로 직접 바꾼다. 배터리 확대 화면의 3D 시험 전원도 조작할 수 있다. 실제 HV 프리차지·접촉기 제어는 아니다.

마지막 **구동 시스템 통합 검증**에서는 직접 신호를 설정하고 최종 토크를 예상한 뒤, 20ms 입력·기대·실제 파형을 비교한다. 기본 3시험과 사용자 시험/예측을 통과하면 같은 모델로 주행한다. 가상 출전자 3대·순위·시상식이 추가됐다. 온라인 대전/충돌 전략 AI는 아니다.

최신 실행파일: **release/Vehicle-Logic-Lab-v0.12.0.exe**. [구현·검증·명시적 후속 범위](docs/V12_SIGNAL_TO_VEHICLE.md). 현재는 전진 구동 EP.01이며, 내연기관 해체→EV 전환 전체·배터리/BMS·회생제동·존/HPC 이식·상용 아트/OEM 납품 완성은 후속 작업이다. 이전 EXE와 ZIP은 자동 갱신하지 않는다.

## 플레이

1. 정상 동작 관찰: 읽기 전용 기준 로직으로 입력과 결과를 먼저 확인합니다.
2. 미션 1: 전원 버튼·브레이크·시스템 준비를 AND로 연결해 진입 요청을 계산합니다. 이 단계에서 차량 상태는 STANDBY를 유지합니다.
3. 미션 2: 전이 조건과 상태 출력을 연결해 OFF → STANDBY → READY → OFF를 구현합니다.
4. 미션 3: 설계를 정상·비정상·경계·버튼 유지 조건으로 시험하고 차량 시스템 지도에서 기능 완성을 확인합니다.

블록 오른쪽 출력 포트 → 왼쪽 입력 포트 순서로 클릭합니다. 제목을 드래그해 블록을 이동하고 빈 공간을 드래그해 화면을 이동합니다. 선이나 블록 선택 후 삭제할 수 있습니다. Ctrl+Z / Ctrl+Shift+Z, 확대·축소, 화면 맞춤을 제공합니다. 다른 위치로 이동한 뒤 연결하려면 확대·축소와 스크롤을 이용하세요.

진행은 현재 브라우저의 `vehicle-logic-lab.v1` 키에만 저장합니다. 주소·포트·브라우저를 바꾸거나 폴더를 옮길 때는 **진행 내보내기 → 불러오기**로 이전하세요. 설계 변경 후 검증 결과는 무효화되며 재시험이 필요합니다. 단순 배치 이동은 판정에 영향을 주지 않습니다. 힌트에는 감점이 없습니다.

```text
src/progress/     저장·복원·설계 지문
src/ui/           Canvas 편집기, 조작·계기판, 미션, 시스템 지도
src/graphics/     TRACKBACK에서 복사한 차량·형상·캐릭터 원본
public/assets/   복사한 차량 도면
tests/           행동·연결·상태·저장·다른 도메인 확장 검증
docs/            개발지시서, 재사용 감사, 가상 사양, 결과·후속 작업
```

기존 레이싱과 추리 게임은 원래 프로젝트에 보존했습니다. 이 폴더에는 필요한 작은 단위만 복사했습니다. 해당 게임 전체를 이 폴더에 포팅한 것은 아닙니다. 새 UI의 테스트 트랙·문제 해결 메뉴는 연동 전까지 `추가 예정`으로 비활성화됩니다.
