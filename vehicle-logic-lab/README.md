# Vehicle Logic Lab

## v0.6 — 새 게임 안에서 직접 운전·제작·시뮬레이션

「새 모험 시작」 → 방향키로 75m 시험 주행 → 차 부품이 흩어지고 원래 모모가 우는 코믹 연출 → 정비소 → 요구사항을 보며 로직 제작 → 신호·부품·차량 리플레이 → 검증 보상 후 내 READY 출력으로 재주행합니다. 기존 본편 앱으로 넘기지 않습니다.

- 화면 드래그로 운전석 시야 이동, 정면·페달·기어 시점 바로가기. 3D 페달 및 화면 페달 누르기, P/R/N/D 선택. ↑/W 가속, ↓/S 제동, ←→/A/D 조향. 방향 전환은 기존 C 제어기의 정차 조건을 따릅니다.
- 기존 C/WASM·Rapier 실행기를 새 게임의 Canvas 안에서 사용합니다. 내 상태가 READY이고 `drive` 출력이 참이며 그래프 오류가 없을 때만 구동을 허용합니다. 첫 장의 진입 요청만으로 차를 움직이지 않습니다.
- 큰 신호 포트를 클릭 두 번(어느 쪽부터든) 또는 드래그로 연결. 짝 포트 강조, 굵은 선·방향 화살표, 신호 펄스, 선 선택·빼기, 되돌리기. 전체 편집기의 기존 자유 설계도 유지합니다.
- 부품 전체 흐름·분해 보기, 논리 아키텍처와 SW 하위 구조, 원본 상태를 보존한 차량 참고자료 탐색. 요구사항은 게임용 사양이고 참고자료의 DRAFT를 정답으로 삼지 않습니다.
- 시동·변속·차량 분해 효과음과 실제 속도·가속 입력에 따른 합성 EV 구동음. 음량 0과 움직임 줄이기 지원.

브라우저: `http://localhost:5175/`. 실행파일: **`release/Vehicle-Logic-Lab-v0.6.0.exe`**. 구버전 앱 창은 닫은 뒤 새 파일을 실행하세요. 저장 형식과 원래 고양이 정체성은 유지했습니다.

253개 자동 테스트 및 별도 렌더링/입체 동작 계약 검사 통과. 브라우저 실플레이·시각 QA는 미완료입니다. 테스트 차량은 SW 조건 평가 후 구동 허용을 보여주는 별도 물리 시연이며, 모든 시나리오의 물리 전제조건을 재현한 통합 검증으로 주장하지 않습니다. [구현·검증·한계](docs/V6_EXPERIENCE_REPORT.md).

## v0.5.1 — 새 게임 진행 유지 · 원래 고양이

사용자 정정에 따라 시작 화면에서 기존 TRACKBACK 본편으로 넘어가던 연결을 제거했습니다. 「새 모험 시작」은 새로 제작한 운전자 시점 인트로 → 정비소 → 차량 내부 → 단계별 로직 조립 → 시험 → 보상으로 진행합니다. 「모험 이어하기」도 같은 새 게임의 저장을 사용합니다. 원래 고양이 얼굴과 그 캐릭터로 수정한 정비소 원화, 입체 부품 및 효과는 유지했습니다.

브라우저: `http://localhost:5175/`. Windows: `release/Vehicle-Logic-Lab-v0.5.1.exe`. 아래 v0.5 본편 연결 설명은 철회된 구현 기록입니다. 기존 엔진·자료는 삭제하지 않고 `simulation/`에 재사용 자산으로 보존하지만, 새 게임의 진입점으로 연결하지 않습니다. 후속 주행·데이터 확장은 새 게임 안에서 단계별로 구현해야 하며, 기존 앱을 여는 방식으로 대체하지 않습니다.

## v0.5 — 철회된 본편 연결 기록

최신 파일: **`release/Vehicle-Logic-Lab-v0.5.0.exe`**. 이전 게임 창을 닫은 뒤 이 파일을 실행하세요. 「본편 시작」은 실제 C/WASM·Rapier 주행 → 고장 기록 → 신호/인터페이스/요구사항 조사 → 시험 → 수리/회귀 → 재주행으로 연결됩니다. 아래 v0.4 실행파일은 보존한 구버전입니다.

W/↑ 가속, S/↓ 브레이크, A/D 또는 좌우 조향, 1–4 P/R/N/D, Esc 메뉴. 화면 페달은 0–100% 압력 조작이며 게임패드도 같은 입력 경계에 연결합니다. 깊은 도구를 바로 쓰려면 의뢰에서 「자유 조사」를 선택하세요. 차량 아키텍처·자료와 입체 부품 도구는 본편 상단에 있습니다. READY 퍼즐은 선택형 입문 모드로 남겼습니다. 기존 캐릭터를 복원했습니다.

기존 25개 + 본편 221개 회귀 통과. v5 브라우저 자동 접근은 차단되어 실제 화면 플레이 검증은 미완료입니다. [정확한 실행 범위·자료 검수·검증 결과](docs/V5_CAMPAIGN_REPORT.md).

## v0.4 그래픽 개편 기록

현재 Windows 단일 실행파일은 **`release/Vehicle-Logic-Lab-v0.4.0.exe`** 입니다. 이전 `Vehicle-Logic-Lab.exe`는 보존한 구버전입니다. 이전 창을 닫고 새 파일을 실행해야 새 그래픽이 보입니다. 이 파일 하나를 복사해서 더블클릭하면 됩니다. 개발 서버·Node.js 설치·브라우저가 필요하지 않습니다. 처음 시작할 때 내장 런타임을 임시 폴더에 풀기 때문에 잠시 걸릴 수 있습니다. 실행 후 F11로 전체 화면, Esc로 메뉴를 열 수 있습니다.

청록·블루·화이트 팔레트, 자체 생성한 정비소/운전석/차량 투시 원화, 반투명 UI, 실시간 3D 페달·제어기·계기판을 적용했습니다. 부품 선택은 위치 확대와 분해 모형으로, 입력 조작은 페달 회전·센서·출력으로, 예측은 점선 구체로 반응합니다. 원화는 고정된 개념 그림이며 실제 동작 판정은 기존 엔진의 Snapshot을 사용합니다. [그래픽 개편·검증·이미지 프롬프트](docs/V4_VISUAL_REPORT.md).

새 모험 → 운전자 시점 인트로 → 정비소 의뢰 → 정상 조작 → 차량 내부 탐험 → 단계별 블록 조립 → 예상·시험 → 회귀 검증 → 보상 순서로 진행합니다. 전체 그래프·자유 편집은 선택적으로 엽니다. 원래의 모든 블록·실행·검증 기능을 보존했습니다.

게임 앱과 개발용 브라우저는 저장 영역이 다릅니다. 게임 메뉴의 진행 내보내기·불러오기로 옮길 수 있습니다. v3는 별도 저장 키를 사용하며 기존 v2 기록을 삭제하지 않습니다. 새 모험을 시작하면 직전 v3 기록을 백업한 뒤 새로 저장합니다.

```powershell
npm ci
npm run dev          # 브라우저 개발 미리보기
npm run package:win  # Windows 단일 exe 빌드
npm run desktop      # 빌드한 exe 열기
```

패키징은 OneDrive 파일 잠금을 피하도록 운영체제 임시 폴더에서 수행하고, 완성한 exe만 release로 복사합니다. 추가 빌드 도구·Electron을 최초로 다운로드할 때는 네트워크가 필요합니다. 빌드된 게임은 오프라인으로 실행합니다. 첫 P0에서는 기존 레이싱 전체 통합 대신 운전자 시점의 짧은 스크립트 오프닝을 사용합니다. 실제 주행 조작/동역학이라고 주장하지 않습니다.

현재 상세 결과는 [V3 보고서](docs/V3_REPORT.md)를 확인하세요. 아래 내용은 이전 v2 구현의 실행·구조 참고입니다.

차량 기능을 직접 연결하고 실행·검증하는 교육용 로직 퍼즐. READY 기능의 3개 미션을 플레이할 수 있습니다. 실제 제조사의 제어 사양이 아닌 명시적인 가상 차량 모델입니다.

## 독립 실행

**이 폴더 전체를 다른 위치로 복사하거나 별도 저장소로 옮길 수 있습니다.** 상위 TRACKBACK 소스·node_modules·서버를 참조하지 않습니다. Node.js 22.18 이상(검증 환경: 24.14)이 필요합니다.

```powershell
cd vehicle-logic-lab
npm ci
npm run dev
```

접속: http://localhost:5175/ — 기존 TRACKBACK의 5173과 구분합니다. 포트가 사용 중이면 다른 포트로 조용히 바뀌지 않고 오류를 표시합니다.

```powershell
npm test
npm run check:independence
npm run build
npm run preview
```

`dist/`는 별도의 정적 호스팅에 배포할 수 있습니다. `node_modules/`와 `dist/`는 소스 전달에서 제외해도 됩니다. 패키지 설치에는 네트워크가 필요하지만 실행 시 외부 폰트·이미지 서버에 의존하지 않습니다. 미리보기 서버는 4175입니다.

## 플레이

1. 정상 동작 관찰: 읽기 전용 기준 로직으로 입력과 결과를 먼저 확인합니다.
2. 미션 1: 전원 버튼·브레이크·시스템 준비를 AND로 연결해 진입 요청을 계산합니다. 이 단계에서 차량 상태는 STANDBY를 유지합니다.
3. 미션 2: 전이 조건과 상태 출력을 연결해 OFF → STANDBY → READY → OFF를 구현합니다.
4. 미션 3: 설계를 정상·비정상·경계·버튼 유지 조건으로 시험하고 차량 시스템 지도에서 기능 완성을 확인합니다.

블록 오른쪽 출력 포트 → 왼쪽 입력 포트 순서로 클릭합니다. 제목을 드래그해 블록을 이동하고 빈 공간을 드래그해 화면을 이동합니다. 선이나 블록 선택 후 삭제할 수 있습니다. Ctrl+Z / Ctrl+Shift+Z, 확대·축소, 화면 맞춤을 제공합니다. 다른 위치로 이동한 뒤 연결하려면 확대·축소와 스크롤을 이용하세요.

진행은 현재 브라우저의 `vehicle-logic-lab.v1` 키에만 저장합니다. 주소·포트·브라우저를 바꾸거나 폴더를 옮길 때는 **진행 내보내기 → 불러오기**로 이전하세요. 설계 변경 후 검증 결과는 무효화되며 재시험이 필요합니다. 단순 배치 이동은 판정에 영향을 주지 않습니다. 힌트에는 감점이 없습니다.

## 구조

```text
src/engine/       타입, 블록 레지스트리, 그래프 검증·평가, 상태 실행, 시험
src/content/      READY 미션·독립 기대값·초기 그래프, 내부 도어 샘플
src/progress/     저장·복원·설계 지문
src/ui/           Canvas 편집기, 조작·계기판, 미션, 시스템 지도
src/graphics/     TRACKBACK에서 복사한 차량·형상·캐릭터 원본
public/assets/   복사한 차량 도면
tests/           행동·연결·상태·저장·다른 도메인 확장 검증
docs/            개발지시서, 재사용 감사, 가상 사양, 결과·후속 작업
```

기존 레이싱과 추리 게임은 원래 프로젝트에 보존했습니다. 이 폴더에는 필요한 작은 단위만 복사했습니다. 해당 게임 전체를 이 폴더에 포팅한 것은 아닙니다. 새 UI의 테스트 트랙·문제 해결 메뉴는 연동 전까지 `추가 예정`으로 비활성화됩니다.
