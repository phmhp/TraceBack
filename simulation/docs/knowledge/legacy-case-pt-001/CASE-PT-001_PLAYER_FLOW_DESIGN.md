# CASE-PT-001 플레이 흐름 개선 설계 / 구현 지시서

상태: 구현 및 개발자 검증 완료, 초심자 플레이테스트 대기. 기존 Ground Truth 승인 상태는 변경하지 않는다.

## 목적과 범위
첫 플레이어가 관측 → 요구사항 대조 → 가설 → 제한된 재시험 → 원인 제출 → 수정 검증을 경험한다. C/WASM 추진 계산 결함 한 건을 대상으로 하며 CAN, Task, Watchdog 및 새 제어 기능은 추가하지 않는다. UI/기록 처리는 호스트 코드이고 제어 결과와 시험 실행은 기존 C를 사용한다.

## 플레이 흐름
1. 정상 주행을 먼저 경험한다. 정상 가속 조건을 누적한 후 결함을 적용한다.
2. 결함 발생 및 기록 확보는 주행 시간, 물리, 입력을 정지시키지 않는다. 정상 구간과 결함 발생 직후 기록을 보존한다.
3. 작은 하단 말풍선으로 현상만 알린다. '다음'으로 조사 안내, 'X-RAY에서 확인'을 선택할 때만 조사 모드로 전환한다. 원인 컴포넌트를 미리 알려주지 않는다.
4. X-Ray에서는 주행을 정지하고 기록을 조사한다. 복귀하면 미해결 상태는 결함을 유지하고 해결 상태는 정상 C 경로를 사용한다. 수동 일시정지 및 창 이탈 시 입력 해제 정책은 유지한다.
5. 사건/신호 추적/요구사항/확인 시험/원인 제출 탭과 상시 요구사항 참조를 유지한다. 도움말은 한 문장, 상세 설명은 접어서 표시한다.
6. 플레이어가 선택한 VMC/eDrive 경계에서 같은 호출의 입력·정상 기대 출력·실제 출력·차이를 비교한다. 기대값은 해당 프레임의 방향·유효성·속력·보정값을 사용하는 명시적 요구사항 기준이며 정상 주행 영상 재현으로 오인시키지 않는다.
7. 기준 시점 A를 지정하고 커서 B를 이동해 신호 전후를 비교한다. 기록 시작/끝과 알림 시점을 표시한다. 기록 첫 프레임은 시스템 초기 상태가 아님을 명시한다.
8. 확인 시험은 격리된 C 인스턴스로 수행한다. 두 입력 제한을 유지하며 모든 시험 이력을 보존하고 제출할 시험을 선택한다. PASS는 해당 조건의 결과만 의미한다.
9. 원인 정답과 증거 충분성을 별도로 평가한다. 정상 시점이나 상류 PASS 시험을 첨부해도 원인 정답 자체를 오답으로 처리하지 않는다. 첫 제출은 보존하고 해설을 제공한다.
10. 수정 전 선택 시험과 동일한 조건을 수정 후 재실행하고 방향별 경계/억제/기어 회귀시험을 함께 표시한다. 다른 조건의 시험을 동일 조건 Replay라고 부르지 않는다.

## UI 원칙
정보를 패널 안에서 줄바꿈하며 값/변수 이름을 구분한다. 시험 이력은 접기, 비교는 간결한 행 형태로 제공한다. 계층 요구사항 지도와 클릭 상세 보기를 유지한다. 말풍선은 차량 중앙을 가리지 않고 버튼 외에는 주행 입력을 방해하지 않는다. 반말을 사용하지 않는다.

## 수용 기준
- 두 실제 맵에서 사건 기록 확보 후에도 clock과 pose가 진행하며 기록은 불변이다.
- 명시적 조사 정지/복귀 및 수정 후 정상 경로, 재시작 초기화를 검증한다.
- 시험을 바꿔도 이전 결과가 보존되고 제출 근거를 선택할 수 있다.
- 정답 판단과 기록/시험 근거 판단은 각각 확인된다.
- 같은 입력·조건의 수정 전후 결과 및 기존 회귀시험을 검증한다.
- 타입 검사, 린트, C+Rapier 사건 테스트 및 가능한 UI 점검을 수행한다.

## 남는 검증
초심자 사용성은 개발자 자체 점검만으로 완료 판정하지 않는다. 첫 사용자에게 '어떤 입력과 출력이 어느 요구사항에서 처음 어긋났는가'를 설명하게 하여 후속 플레이테스트한다. 실제 ECU/HIL/통신 검증을 완료했다고 주장하지 않는다.

- 정상 가속 조건 누적 5초 이후 결함을 적용하고, 이후 2초 구간을 확보한다. 고장 직후 페달을 떼어도 기록 확정이 무기한 지연되지 않는다.

- VMC/eDrive 기대값 대조, A/B 출력 비교, 접을 수 있는 입력 조건, 시험 이력 및 선택, 원인/증거 분리 평가, 선택 시험 2건 재실행 + 기존 회귀 18건을 적용했다.
- `npm.cmd run typecheck`, `npm.cmd run lint`, `node --test tests/case-gameplay.test.mjs` 통과(7건). 두 맵에서 기록 후 주행 지속, 기록 불변, 명시적 정지 및 정상 복구를 포함한다.
- 비교 대상은 현재 구현된 경계 신호이며 전체 시스템 초기 상태 복원이나 차량 물리의 결정론적 Replay는 구현하지 않았다. 창 이탈 시 자동 일시정지는 별도 기존 정책으로 남는다.
